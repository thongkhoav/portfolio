## Tech Stack

- Next.js 16 and React 19
- Tailwind CSS 4 and Sass
- Node.js built-in test runner

## Content Configuration

Shared profile information lives in `utils/data/personal-data.js`. Experience, education, skills, and project content live in the other files under `utils/data/`.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

```bash
npm test
npm run lint
npm run build
```
